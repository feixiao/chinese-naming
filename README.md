## 🎯 为什么需要 `pm-chinese-naming`？

在华人文化背景下，起名是牵动三代人情感的严肃大事。然而现存方案充满痛点：
* **通用大模型原生问答**：文采斐然但存在致命“理科幻觉”——算错经纬度真太阳时、分不清八字调候用神（盲目“缺啥补啥”）、甚至捏造诗经名句；
* **传统周易起名网**：充斥 2005 年代的弹窗广告、虚假的“99分”和机械堆砌（“鑫森淼焱”），充满诈骗感；
* **市面 AI 起名小程序**：90% 是廉价 Prompt 套壳，起出来的名字全是“梓涵/子轩/雨泽”等烂大街网文风；
* **家庭决策断层**：年轻人想要清新审美，长辈想要传统五行规矩，缺乏一份能平息博弈的“共识交付物”。

`pm-chinese-naming` 通过**确定性算法底座 + 正统典籍溯源 + 长辈说服文书**，彻底解决以上顽疾。

## 🏗️ 两段式解耦系统架构

```
[用户输入] (姓氏 + 公历时间 + 城市 + 性别 + 风格)
          │
          ▼
┌─────────────────────────────────────────────────────────────┐
│ 阶段一：确定性理科前置校验 (scripts/engine.py 纯标准库)       │

│  2. 四柱八字排盘 (节气交节判定、23:00~24:00 夜子时正统划分)    │
│  3. 调候五行急救评估 (冬生急取丙火解冻、夏生急取壬水润局)      │
│  4. 平水韵/中华新韵平仄声律过滤 (平平仄/仄平平，杜绝拗口)      │
│  5. 现代千禧重名潮与校园不雅谐音梗安全拦截                    │
└──────────────────────────────┬──────────────────────────────┘
                               │ 输出约束集 (补益偏旁 + 推荐平仄 + 避开字)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 阶段二：文科意象与典籍 RAG 升华 (LLM Cultural Synthesis)      │
│  1. 正统善本溯源 (《诗经》《楚辞》《古诗十九首》《唐宋文选》) │
│  2. 字形与六书演变 (甲骨文、金文、《说文解字》本义)          │
│  3. 成果级交付物 (五维雷达图 + 考据白皮书 + 独家长辈说服卡)   │
└─────────────────────────────────────────────────────────────┘
```

安装该 Skill 后，可在任何支持 Agent Skills 的终端中直接使用如下指令：

| 快捷指令 | 目标场景 | 核心输入 | 标准结构化交付物 |
| :--- | :--- | :--- | :--- |
| **`/name baby`** | 新生儿全流程严谨起名 | 姓氏、出生时间地点、性别、风格 | 候选名字矩阵 + 考据白皮书 + 长辈说服卡 |

| **`/name elder`** | 针对指定名字生成长辈说服文书 | 选定名字、家庭顾虑点 | 《致长辈：文化渊源与五行通和说明书》 |
| **`/name scaffold`** | 生成小程序/Web 起名独立项目脚手架 | 目标平台（小程序/H5） | 确定性排盘算法脚本 + 带调试栏单文件原型 |

## 🚀 快速上手与使用

### 1. 独立运行确定性排盘与声律引擎
本引擎无需任何外部依赖（纯 Python 3.8+ 标准库）：

```bash
# 运行完整起名与安全性体检
python3 scripts/engine.py --date "2026-08-15 14:30" --city "杭州" --surname "陈" --name "言溪"

# 导出原始 JSON 供小程序或后端 API 消费
python3 scripts/engine.py --date "2026-08-15 14:30" --city "杭州" --surname "陈" --name "言溪" --json
```

## 🎨 单文件交互原型 (`prototypes/naming-card.html`)

仓库内置一份无外部编译依赖的单文件交互原型，包含 **`🛠️ PM 评审状态切换器`**：
* 状态 1：正常提案展示（含 SVG 五维雷达图与字形演变）；
* 状态 2：空状态；
* 状态 3：算法排盘加载中；
* 状态 4：千禧重名潮与谐音梗拦截异常；
* 状态 5：独家《长辈说服沟通卡》（可一键复制文书）。

直接在浏览器中双击 `prototypes/naming-card.html` 即可预览交互。
